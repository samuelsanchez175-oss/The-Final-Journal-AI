Ghost Free × 70-artist (actually 784 in sqlite) pipeline

  1. Vault — gzipped SQLite of Genius bars. Row: line, artist, song, syllables, end_word, phonetic_class (CMUDICT from last primary stress, e.g. bone → OW1 N).
  2. Index — CatalogEndWordIndex samples end words: {word, phones, rhymeClass, artist, song, wrap}.
  3. On a written line — last word + wrap + phonetic class.
  4. Lookup — same class, prefer similar wrap, then rest of class, then live GROUP BY end_word ORDER BY n.
  5. Fill — CMUDICT if still short; drop dictionary junk (boan).
  6. UI — up to 40 chips, two rows, sticky until the class changes. Word heads only.

Catalog MIR vs Bar hits

MIR writes per-song records (artist|title): audio → BPM/key/scale; lyrics-only those stay null; style tags still fill at low confidence. Not used as a Bar hits ranker — almost the whole vault has no audio, so matching the note’s BPM would drop real wrap hits with no proof of better bars.
